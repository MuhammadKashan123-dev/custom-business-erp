# ERP
This is a ERP Project that I was Working on Recently Started with Simple Back-End Development than slowly into a Full-Stack Project. Now In Future Will Add AI Integration.

## Description
This Started as a Learning Project Slowly Transformed into a Whole Web Application. First Only Had Backend Now Has Front-End and Will Integrate AI into it as well making it a Full AI Software.

---

## Features

### Full Features

- Rest API
- Check Employees Tab To Manage Employees
- CRUD Integrations to Manage Update and Delete Employees
- Inventory tab To Check All Your Current Inventory
- Orders Tab To Order Products
- Analytics Dashboard For Sales Tracking
- Profile Endpoint

  ### Tech-Stack

  - Python
  - FastAPI
  - PostgreSQL
  - HTML
  - CSS
  - SQLAlchemy
  - Jinja2
